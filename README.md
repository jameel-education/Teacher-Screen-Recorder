# Teacher Screen Recorder + Clip Combiner

## Free Windows Video Lesson Recording Software for Teachers

### Version 1.1.0 | November 2026

Developed by **JameelEdu**

Teacher Screen Recorder + Clip Combiner is a free, offline Windows desktop application developed to help teachers, lecturers, trainers and other educators create recorded lessons, demonstrations, presentations and educational videos.

The software focuses on video lesson recording, with additional tools for preparing audio narration and combining short recordings into longer, continuous lessons.

Teachers can create educational videos using an ordinary computer, a microphone, an optional webcam and a quiet room, without requiring expensive recording studios or commercial video recording software.

The application is designed to be simple, practical, multilingual and accessible to educators worldwide.

## Main Features

### Screen Recorder

- **Flexible Screen Recording:** Record selected screen areas, classroom demonstrations, presentations, teaching boards and other on-screen activities.
- **Recording Quality:** Choose from 720p, 1080p and 4K recording options.
- **Recording Formats:** Flexible recording formats suitable for different display and presentation requirements.
- **Webcam Overlay:** Include an optional webcam view in recorded lessons.
- **Background Blur:** Adjust webcam background blur for a more professional presentation.
- **Webcam Size:** Adjust the size of the webcam overlay.
- **Presenter Nameplate:** Display the presenter's name in the recorded video.
- **Institutional Logo:** Personalise recordings with an institutional or custom logo.
- **Microphone Recording:** Record voice narration with audio synchronisation controls.
- **System Audio Recording:** Capture computer audio using Windows WASAPI.
- **Audio Gain:** Adjust recording audio levels.
- **Narration from Audio Files:** Create screen recordings using previously recorded narration.
- **Mouse Highlighting:** Make the mouse pointer easier to follow during demonstrations.
- **Click Effects:** Highlight mouse clicks during recorded lessons.
- **Built-in Video Player:** Review completed recordings directly.
- **Local Processing:** Record and process videos on the user's computer.

### Multilingual Nameplates

Version 1.1.0 introduces a flexible multilingual nameplate system designed to support educators from different linguistic backgrounds.

Features include:

- Automatic detection of the active Windows keyboard language.
- Unicode text support.
- Left-to-right and right-to-left writing support.
- Language-specific font preferences.
- Custom font importing.
- Adjustable nameplate font sizes.
- Remembered language-specific font preferences.

Teachers can display their names in their preferred language, subject to appropriate keyboard and font availability.

The application interface is currently in English.

### Audio Recorder

The dedicated Audio Recorder allows teachers to prepare narration independently before creating video lessons.

Features include:

- Microphone audio recording.
- Audio recording gain controls.
- Audio preview and playback.
- Background noise reduction.
- Voice enhancement presets.
- Environmental audio enhancement options.
- Audio file saving for later use in recorded lessons.

### Clip Combiner

Clip Combiner is a simple utility included with Teacher Screen Recorder.

Its primary purpose is to **join shorter recorded clips into a longer continuous video**, particularly when teachers prepare lessons in several recording sessions.

Teachers can arrange and duplicate clips before combining them into a continuous lesson video.

It is not intended to replace dedicated video editing software.

Users requiring advanced video editing can use a separate video editing application.

## Minimum System Requirements

- **Operating System:** Windows 10 or Windows 11 (64-bit).
- **Processor:** 64-bit dual-core processor or better.
- **Memory (RAM):** 4 GB minimum; 8 GB or more recommended.
- **Storage:** At least 1.5 GB of free space for installation.
- **Webcam:** Optional; required for webcam recording.
- **Microphone:** Optional; required for microphone narration.
- **Internet Connection:** Not required for normal operation.
- **Administrator Privileges:** Not normally required for standalone installation or everyday use.

Higher-performance computers are recommended for 4K recording, webcam background blur and demanding media-processing tasks.

Performance may vary depending on computer specifications and recording settings.

## Recording and Processing Storage

Video recording and processing require additional temporary disk space.

As a practical estimate, a 10-minute recording may require approximately **5 GB of free disk space** during recording and processing. Actual storage requirements depend on recording quality, screen dimensions and recording duration.

The final MP4 file is generally much smaller.

Temporary raw recording files are automatically removed following successful export. If processing fails, temporary recordings may be retained to allow recovery.

For longer lessons, teachers are encouraged to record shorter sections and combine them using Clip Combiner.
